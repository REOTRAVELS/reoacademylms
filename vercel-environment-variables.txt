NOTES

- Use Neon’s pooled connection URL for DATABASE_URL at runtime. Use its direct
  URL only for one-off database migrations.
- Use an Upstash TLS connection URL beginning with rediss:// for REDIS_URL.
  Do not include a redis-cli command or use the Upstash REST URL/token.
- Use the B2 bucket name, not its bucket ID, and a bucket-restricted key.
- Vercel supplies VERCEL automatically; do not add it yourself.
- SMTP_URL and SMTP_FROM are omitted because this setup uses Brevo’s HTTPS API.
- The previous values were exposed. Revoke/rotate the Neon database password,
  Upstash token, Brevo API key, LiveKit API credentials, and B2 application key
  before using this deployment. Generate a new JWT secret as well.
